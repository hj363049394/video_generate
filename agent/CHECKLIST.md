# 发布前终审清单（CHECKLIST）

> 交付前必查的 9 项标准。每一项必须通过，否则视为交付失败。
> 由 router 在任务执行过程中自动完成代码层检查（#1-#4），由人工完成内容层检查（#5-#9）。

## 检查清单（9 项）

### 1. 原创度自检是否通过（代码自动）

- [ ] 字符 3-gram Jaccard 相似度 ≤ 0.30（POC 定稿阈值，验收样例 0.014）
- 检查位置：`pipeline/rewrite.py` 的 `run_rewrite()` 返回的 `similarity` 字段
- 超阈值：抛 RuntimeError，任务标记为 failed，提示人工复写

### 2. 不复用对标原图（代码自动）

- [ ] 全组图底图均为新生成（ark 双通道产出），无对标笔记原图 URL 引用
- 检查位置：`pipeline/imagepack.generate_pack` 输出的 cards 路径
- 异常：发现 image_units 中包含对标原图 URL 即判失败

### 3. 内容单元 JSON 结构完整（代码自动）

- [ ] 标题（≤20 字，沿用对标钩子类型）
- [ ] 正文（结构骨架与对标一致，含结尾服务钩子）
- [ ] 标签（≥3 个，含大流量词 + 精准词搭配）
- [ ] image_units（≥2 个，含 cover + page 角色）
- 检查位置：`pipeline/rewrite.parse_llm_output` 输出

### 4. 视频规格合规（代码自动）

- [ ] 分辨率 1080×1440（3:4 竖版）
- [ ] 帧率 25 fps
- [ ] 时长 30-90s（短于 30s 信息密度不足，长于 90s 节奏拖沓）
- [ ] 文件大小 ≤ video_max_mb（默认 25MB，V4 实测后调整）
- 检查位置：`pipeline/video.make_video` 输出 + deliver_video 阈值判断

### 5. 同构异题是否到位（人工）

- [ ] 结构骨架与对标一致（逐段功能对齐：钩子→痛点→干货→服务钩子）
- [ ] 主题细节全部替换（点位/案例/数据 100% 替换，无原案例残留）
- [ ] 标签结构逻辑与对标一致（大流量词 + 精准词），但具体词条已替换
- [ ] 替换幅度到"一眼是新内容"
- 人工对照：rewrite.json 的 content 与对标 description 逐段对比

### 6. 图文同源是否到位（人工）

- [ ] 第 N 段视频旁白只讲第 N 张图上承载的内容，无串图
- [ ] 旁白与图上信息一一对应（无图上没讲的、无图上讲了旁白没讲的）
- [ ] 旁白口语化（去 emoji、去标签符号、短句）
- 人工对照：layout.json 的 narrations 与 video_frames 逐镜核对

### 7. 视觉风格是否统一（人工）

- [ ] 全组图共用同一组风格锚点，色调统一
- [ ] 封面与内页风格连续（不能封面是风景、内页全是文字大字报）
- [ ] 信息密度高的内容（路线表/点位卡）用排版卡片承载，AI 图只做横幅与情绪图
- [ ] 中文文字全部由排版层（PIL）渲染，无 AI 画字错字变形
- 人工对照：4 张成品图 + 5 张视频帧

### 8. 是否无虚构资产（人工）

- [ ] 无虚构账号自有 IP（如"亲子民宿绿皮书"这类不存在的资产）
- [ ] 无虚构合作资源（如"与 XX 景区独家合作"等未发生的合作）
- [ ] 无虚构独家权益（如"内部价""专享通道"等不存在的权益）
- 风险提示：deepseek-v4-pro 模型有虚构资产倾向（§8.2 实测发现），仅作 fallback 兜底

### 9. 服务钩子是否对齐人设（人工）

- [ ] 正文结尾含服务钩子（"评论区报：人数 / 天数 / 预算，帮你重排一版"）
- [ ] 钩子与账号变现路径一致（旅游行程定制服务）
- [ ] 住宿卡 CTA 三行齐全（line1 说明 / line2 报数格式 / line3 承诺）
- 人工对照：rewrite.json 的 content 末段 + stay_hook.cta

## 常见质量问题与修复

| 问题 | 原因 | 修复方式 |
|---|---|---|
| 原创度超阈值 | LLM 偷懒，复用原文片段 | 在 prompt 中强化"不得复用原文连续 8 字以上片段" |
| 串图 | LLM 编排阶段未保证图文同源 | 在 LAYOUT_PROMPT 中明确铁律（已强化） |
| 风格不统一 | 不同图用了不同风格锚点 | 全组图共用同一组风格锚点（imagepack 已做） |
| 中文画字变形 | AI 出图含中文字 | 中文一律不让 AI 画，全部 PIL 渲染（已做） |
| 虚构资产 | deepseek-v4-pro 兜底时虚构 | 主力用 kimi-k3，deepseek 仅 fallback 兜底 |
| 视频超阈值 | 30MB > 25MB 默认值 | V4 实测后调 video_max_mb；或调码率 |
| BGM 防盗链 403 | Pixabay CDN 防盗链 | 用 Incompetech 直链（已踩平） |
| TTS 报 55000000 | 音色不兼容（用 moon 系） | 仅用 `*_uranus_bigtts`（2.0 系） |
