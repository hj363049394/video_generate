## 检查清单（9 项）

### 1. 原创度自检（代码自动 · 阻塞）

- [ ] 字符 3-gram Jaccard 相似度 ≤ 0.30（POC 定稿阈值，验收样例 0.014）
- 实现：`pipeline/rewrite.py` `run_rewrite()`；`router._run_task` 超阈值直接判 failed

### 2. 不复用对标原图（代码自动 · 阻塞）✅ v1.3 实装

- [ ] 全部生图提示词不引小红书图床/链接域名（xiaohongshu.com / xhslink.com / xhscdn / sns-img）
- 实现：`pipeline/rewrite.py` `contains_benchmark_url()`——仿写 image_units 与版式
  cards/rows 的提示词两处拦截，命中即任务失败

### 3. 内容单元结构完整（代码自动 · 阻塞）✅ v1.3 实装

- [ ] 标题非空（>20 字降级为警告进质量报告——平台标题栏会截断）
- [ ] 正文 ≥ 50 字、含结尾服务钩子（钩子由提示词约束）
- [ ] 标签 ≥ 3 个
- [ ] image_units ≥ 2 个且每个含生图提示词
- 实现：`pipeline/rewrite.py` `validate_rewrite_output()`——硬失败自动重试一次，
  仍失败任务失败（LLM 非确定性，重试显著提升通过率）

### 4. 视频规格合规（代码自动 · 不阻塞）

- [ ] 分辨率 1080×1440、帧率 25fps（ffmpeg 参数保证）
- [ ] 时长 30-90s（超范围告警进质量报告，不阻塞交付）
- [ ] 文件大小 ≤ video_max_mb（超限自动降级提示人工取件）
- 实现：`bot/quality.py` `probe_video/check_video_spec`；视频经 `/视频 任务ID` 按需生成后判定

### 5. 同构异题是否到位（人工）

- [ ] 结构骨架与对标一致（逐段功能对齐：钩子→痛点→干货→服务钩子）
- [ ] 主题细节全部替换（点位/案例/数据 100% 替换，无原案例残留）
- [ ] 标签结构逻辑与对标一致（大流量词 + 精准词），但具体词条已替换
- [ ] 替换幅度到"一眼是新内容"
- 对照：rewrite.json 的 content 与对标 description 逐段对比

### 6. 图文同源是否到位（人工）

- [ ] 第 N 段视频旁白只讲第 N 张卡上承载的内容，无串图
- [ ] 旁白与卡上信息一一对应（无卡上没讲的、无卡上讲了旁白没讲的）
- [ ] 旁白口语化（去 emoji、去标签符号、短句）
- 对照：layout.json 的 narrations 与 cards 逐卡核对

### 7. 视觉风格是否统一（人工）

- [ ] 全组卡共用同一组风格锚点，色调统一
- [ ] 封面与内页风格连续（不能封面是风景、内页全是文字大字报）
- [ ] 信息密度高的内容（清单/路线/要点）用 banner+块承载，AI 图只做底图与情绪图
- [ ] 中文文字全部由排版层（PIL）渲染，无 AI 画字错字变形
- 对照：images/ 目录 3-6 张成品卡

### 8. 是否无虚构资产（人工）

- [ ] 无虚构账号自有 IP（如"亲子民宿绿皮书"这类不存在的资产）
- [ ] 无虚构合作资源（如"与 XX 景区独家合作"等未发生的合作）
- [ ] 无虚构独家权益（如"内部价""专享通道"等不存在的权益）
- 风险提示：deepseek-v4-pro 模型有虚构资产倾向（§8.2 实测发现），仅作 fallback 兜底

### 9. 服务钩子是否对齐人设（人工）

- [ ] 结尾钩子与**内容方向**匹配（SOUL.md 钩子策略表）：行程规划类=定制服务硬钩子（报人数/天数/预算）；旅行知识类=关注看合集；人生与旅行类=关注共鸣+互动提问；好物类=关注拿清单
- [ ] 情绪型内容**没有**硬挂定制服务钩子（伤互动）
- [ ] 末卡 CTA 四行齐全（line1 过渡 / line2 钩子主体 / line3 承诺 / account 关注）
- 对照：rewrite.json 的 content 末段 + layout.json 末卡 cta 块

## 常见质量问题与修复

| 问题 | 原因 | 修复方式 |
|---|---|---|
| 原创度超阈值 | LLM 偷懒复用原文片段 | rewrite.md 已强化"不得复用原文连续 8 字以上片段" |
| schema 校验失败 | LLM 偶发输出缺字段/单元不足 | 自动重试一次；仍失败查 rewrite.md 输出格式段 |
| 串图 | 编排阶段未保证图文同源 | layout.md 铁律"第 N 段旁白只讲第 N 张卡" |
| 风格不统一 | 不同卡用了不同风格锚点 | layout.md 约束全组共用风格锚点 |
| 中文画字变形 | AI 出图含中文字 | 中文一律 PIL 渲染（生图提示词强制"无文字"） |
| 虚构资产 | deepseek-v4-pro 兜底时虚构 | 主力 kimi-k3，deepseek 仅 fallback；人工项 #8 终审 |
| 视频超阈值 | 成片 > video_max_mb | 提示人工取件；压缩降级属后续 D3 |
| 视频时长越界 | 镜头数/旁白长度导致 <30s 或 >90s | 质量报告告警；调 layout.md 旁白 30-60 字约束 |
| BGM 防盗链 403 | Pixabay CDN 防盗链 | 用 Incompetech 直链（已踩平） |
| TTS 报 55000000 | 音色不兼容（用 moon 系） | 仅用 `*_uranus_bigtts`（2.0 系） |
