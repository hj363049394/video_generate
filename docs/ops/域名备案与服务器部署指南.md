## 1. 前置条件清单（缺一不可）

- [ ] **主体资质**：企业营业执照 或 个体工商户执照（R16 决策：主体必须为企业/个体工商户，个人主体无法开通微信支付、AIGC 备案受限）
- [ ] 法人身份证正反面照片 + 备案负责人手机号（可用法人本人）+ 邮箱
- [ ] 云厂商账号（推荐**阿里云**或**腾讯云**，备案代提交流程成熟；账号建议直接用企业信息注册并完成**企业实名**）
- [ ] 营业执照**经营范围**含「软件开发 / 信息技术服务 / 技术咨询」类字样（备案与 AIGC 登记都会核对；个体户若经营范围不符，可先去市场监管做经营范围变更，约 3–5 个工作日）

> **域名、服务器、备案、服务号认证四者的主体必须一致**（同一企业/个体户）。先用一个企业云账号统一办理，避免后期主体不一致被驳回重办。

## 2. 购买域名（30 分钟）

### 2.1 选域名

| 建议项 | 说明 |
|---|---|
| 后缀 | 首选 `.com` / `.cn`（备案最稳）；`.app` `.fun` `.cn` 等新顶级域**多数已可备案**，但个别省份管局仍保守，**稳妥起见用 .com** |
| 名称 | 短、好记、与产品相关：如 `chaijie.fun`、`boka.chaijie.cn` 形态。主域名建议直接买 `.com` |
| 价格 | .com 约 ¥55–80/年；.cn 约 ¥25–35/年（首年促销更低） |

### 2.2 操作步骤（阿里云万网示例）

1. 访问 `wanwang.aliyun.com`，搜索心仪域名 → 加入清单 → 结算（**用已企业实名的云账号购买**，注册人信息自动继承企业主体）
2. 进入 **域名控制台 → 实名认证**：上传营业执照 + 法人身份证，选「企业」类型，提交
3. 等待实名审核（CNNIC 通道，通常 **1–3 个工作日**），状态变为「已实名（企业）」后方可提交备案
4. **暂不解析、暂不建站**——备案期间域名必须处于不可访问状态（见 §4.4）

> 避坑：① 不要用个人身份买域名再想做企业备案——主体不一致直接驳回；② 域名注册商与服务器厂商可以不同（如域名在阿里云、服务器在腾讯云），但备案要跟着**服务器所在厂商**走（腾讯云备案系统可添加外部注册域名）。

## 3. 购买云服务器（30 分钟）

### 3.1 配置建议（MVP 起步）

| 项 | 建议 | 说明 |
|---|---|---|
| 机型 | 轻量应用服务器 或 ECS **2 核 4G** | 本项目负载：FastAPI API + 抓取/生成 worker（技术方案 §2 流水线）+ Redis；ASR（faster-whisper）与视频合成按技术方案走 GPU/弹性节点，不压在主机上 |
| 地域 | 华东（杭州/上海） | 离主力用户近；备案归属省份 = 云厂商接入地相关，按营业执照归属地管局审核 |
| 系统 | Ubuntu 22.04 LTS | 技术方案部署基线 |
| 计费 | **必须「包年包月」且 ≥3 个月** | 按量计费实例**无法生成备案服务码**，这是硬性要求；预算紧可先买 3 个月，备案通过后续费 |
| 带宽 | 按流量计费 5–10 Mbps 峰值 | 图卡/视频走 OSS + CDN，不占主机带宽 |
| 价格 | 见 §13 厂商对比——**首推阿里云 ECS u1 2核4G ¥199/年（续费同价，企业实名可购）**；轻量 2C4G 新用户 ¥379/年但次年恢复原价约 ¥840/年 | |

### 3.2 购买后立即做的三件事

1. **申请备案服务码**：ECS 控制台 → 实例详情 → 「备案信息」→ 申请服务码（一台服务器可申请有限个数，供备案系统使用）
2. **安全组**：仅放行 `22`（建议改高端口或限办公 IP）、`80`、`443`
3. 记录**公网 IP**，备用（内网联调用）

## 4. ICP 备案详细流程（核心章节）

> 入口：阿里云 `beian.aliyun.com` → 「开始备案」。腾讯云：console.cloud.tencent.com → 备案。

### 4.1 提交流程（6 步）

1. **填写主体信息**：企业名称、统一社会信用代码、营业执照上传、法人身份证、备案负责人信息（可=法人）
2. **填写网站信息**：
   - 域名：选定域名
   - **网站名称**：⚠️ 高频驳回点。不能含「中国/国家/中央」等字样、不能是纯个人姓名、不能有明显营销夸大。**建议用中性名**：如「拆解仿写工具」「爆款拆解助手」；「爆款」二字部分管局可能认为夸大宣传，被驳回就换「拆解仿写工具」重提
   - 网站首页 URL：`https://www.你的域名.com`
   - **服务内容**：勾「应用软件 / 软件开发 / 工具」类；**不涉及**前置审批项（新闻、出版、教育、医疗、药品、金融、文化、广播电影电视均不勾——本产品是文案辅助工具）
   - 备注：可写「面向内容创作者的文案辅助工具网站」
3. **上传资料**：域名证书（域名控制台可导出）、备案承诺书（系统生成，打印签字拍照）、部分省份需要法人手持身份证照
4. **人脸核验**：备案负责人用阿里云 App 扫码完成活体检测
5. **阿里云初审（1–2 个工作日）**：期间客服可能来电核实网站用途——如实回答「企业自营的文案创作辅助工具」。初审会检查：
   - ✅ 域名已实名且主体一致
   - ✅ 服务器包月 ≥3 个月 + 备案服务码有效
   - ✅ **域名处于关站状态**（见 4.4）
6. **提交管局审核（各省 1–20 个工作日，多数 1–2 周）**：
   - 部分省份管局会向备案负责人手机发**短信验证码**（24 小时内完成），留意短信别错过
   - 通过后收到短信 + 邮件，含**备案号**（形如 `沪ICP备2026XXXXXX号-1`）

### 4.2 拿到备案号后必须做的两件事

1. **网站底部悬挂备案号**，并超链接到工信部备案系统 `https://beian.miit.gov.cn`——这是《非经营性互联网信息服务备案管理办法》要求，管局年检抽查项（前端页脚统一组件实现）
2. **30 日内办理公安备案**（见 §5）

### 4.3 高频驳回原因与预防

| 驳回原因 | 预防 |
|---|---|
| 网站名称不规范 | 用中性工具名，避开「爆款」等夸大词 |
| 域名/服务器/主体信息不一致 | 全部走同一企业账号 |
| 营业执照经营范围与网站内容不符 | 经营范围含「软件开发/信息技术服务」 |
| 备案期间域名可访问 | 见 4.4，保持关站 |
| 短信核验超时 | 提交后 3 周内保持负责人手机畅通 |

### 4.4 备案期间域名关站要求（重要）

管局审核时会核验域名可访问性——**首次备案期间，域名不得提供任何公开网页服务**：

- 域名**不做 DNS 解析**（最干净），或解析到一个空记录
- 开发联调走 **IP + 非标端口**（如 `http://1.2.3.4:8000`），微信网页授权此时用不了——正常，微信侧配置等备案后（§9.8 给出内网联调方案）
- 云厂商初审若提示「域名可访问」，先去 DNS 控制台删除解析再重提

### 4.5 后续变更须知

- 换云厂商/换服务器 IP：做「**接入备案**」转移（新厂商提交接入，不换备案号），期间网站**不得关站**
- 网站长期（通常 3 个月+）无法访问或内容违规：备案号可能被注销，微信侧全部域名配置随之失效

## 5. 公安备案（ICP 备案通过后 30 日内）

本项目含用户注册与内容生成（属「交互式网站」），原则上需办理：

1. 访问全国互联网安全管理服务平台 `www.beian.gov.cn` → 注册（主体=同一企业）
2. 提交：主体信息 + 网站信息（域名、备案号、服务类型勾「其他」/「应用软件」，开设交互服务情况如实填写）
3. 属地网警审核（约 5–10 个工作日）
4. 获公安备案号（形如 `沪公网安备 31010XXXXXXXXX号`）→ **页脚与 ICP 备案号并排悬挂**，链接到 `www.beian.gov.cn`

## 6. 微信侧域名配置（备案通过后 30 分钟）

前提：**已认证服务号**（¥300/年，mp.weixin.qq.com → 设置与开发 → 微信认证）。认证主体与备案主体一致。

公众平台 → 设置与开发 → 公众号设置 → **功能设置**，配置三个域名（均需备案）：

| 配置项 | 作用 | 不配的后果 |
|---|---|---|
| **业务域名** | 微信内打开该域名不出现「非微信官方网页」提示 | 用户点开 H5 被安全提示吓退 |
| **JS 接口安全域名** | 微信 JS-SDK（分享卡片、图片保存等） | JS-SDK 全部失效 |
| **网页授权域名** | **snsapi_base 静默登录的生命线**（FR-01 通道 A） | 微信内打开 H5 无法拿 openid，登录退化为手机号 |

操作：每个域名配置都要求**下载 `MP_verify_xxxx.txt` 校验文件**，放到服务器该域名**根目录**可访问（`https://你的域名.com/MP_verify_xxxx.txt` 返回 200）→ 提交校验。

> 避坑：① 测试号不支持正式的网页授权域名（只能 IP 调试），**联调必须等备案 + 校验文件就位**；② 三个域名可填同一主域；③ 每月修改次数有限，规划好再填。

**微信支付**（官网收款页需要）：mp.weixin.qq.com → 微信支付 → 申请商户号（企业资质，约 1–5 个工作日）→ 绑定服务号 + 配置 H5 支付/ Native 扫码支付。对齐 PRD：**微信内 H5 不收款**，收款页在系统浏览器/桌面端打开。

## 7. AIGC / 算法登记（与备案并行启动）

技术方案 §9.1 已列为上线前置事项，对齐《生成式人工智能服务管理暂行办法》与《互联网信息服务深度合成管理规定》：

1. 入口：互联网信息服务算法备案系统 `beian.cac.gov.cn`（网信办）
2. 形态：本项目属「生成合成类算法」服务——主体备案信息填报 + 算法安全自评估报告 + 拟公示信息
3. 材料：营业执照、算法机制说明（拆解→仿写流水线）、安全评估（内容安全检测机制 = PRD FR-11）、用户协议/隐私协议文本

5. 完成后在官网页脚公示登记/备案编号

## 9. 服务器部署实操（Ubuntu 22.04，对齐技术方案架构）

架构：`Nginx（静态前端 + /api 反代）→ FastAPI（uvicorn 多 worker）→ PostgreSQL + Redis`，后台任务（抓取/仿写/生图/回采）跑独立 worker 进程，对象存储放图卡/视频产物。

### 9.1 基础安全初始化

```bash
adduser deploy && usermod -aG sudo deploy
# SSH 密钥登录 + 禁 root 密码（本地生成密钥后）
ssh-copy-id deploy@服务器IP
sudo sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin no/;s/^#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart ssh
sudo ufw allow 22 && sudo ufw allow 80 && sudo ufw allow 443 && sudo ufw enable
sudo apt install -y fail2ban
```

### 9.2 安装依赖

```bash
sudo apt update && sudo apt install -y nginx postgresql redis-server git
# PostgreSQL 建库（库名/账号按技术方案 §3 DDL）
sudo -u postgres psql -c "CREATE USER chaijie WITH PASSWORD '强密码';"
sudo -u postgres psql -c "CREATE DATABASE chaijie OWNER chaijie;"
```

### 9.3 前端部署（静态）

```bash
sudo mkdir -p /var/www/chaijie
# 本地打包产物上传（H5 为纯静态资源——产品效果图即单 HTML，正式版为构建产物）
sudo rsync -av dist/ /var/www/chaijie/current/
```

### 9.4 Nginx 配置

```nginx
# /etc/nginx/sites-available/chaijie
server {
    listen 443 ssl http2;
    server_name 你的域名.com www.你的域名.com;
    # ssl_certificate 路径由 certbot 自动填充

    root /var/www/chaijie/current;
    index index.html;
    location / { try_files $uri $uri/ /index.html; }   # SPA 路由兜底

    location /api/ {
        proxy_pass http://127.0.0.1:8100;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 300s;                        # 视频合成类长请求
    }
    client_max_body_size 220m;                          # FR-14 视频上传 200MB 上限
    gzip on; gzip_types text/css application/javascript application/json;
}
server { listen 80; server_name 你的域名.com www.你的域名.com; return 301 https://$host$request_uri; }
```

```bash
sudo ln -s /etc/nginx/sites-available/chaijie /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

### 9.5 后端部署（systemd 托管 uvicorn + worker）

```ini
# /etc/systemd/system/chaijie-api.service
[Unit]
Description=chaijie FastAPI
After=network.target postgresql.service redis-server.service
[Service]
User=deploy
WorkingDirectory=/srv/chaijie
EnvironmentFile=/srv/chaijie/.env          # 技术方案 §7 配置（含密钥，chmod 600）
ExecStart=/srv/chaijie/.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8100 --workers 2
Restart=always
[Install]
WantedBy=multi-user.target
```

```ini
# /etc/systemd/system/chaijie-worker.service（抓取/生成/回采队列，同法）
ExecStart=/srv/chaijie/.venv/bin/python -m worker.main
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now chaijie-api chaijie-worker
```

### 9.6 数据库每日备份

```bash
# crontab -e（deploy 用户）
0 3 * * * pg_dump -U chaijie chaijie | gzip > ~/backups/chaijie_$(date +\%F).sql.gz && find ~/backups -mtime +14 -delete
```

### 9.7 图卡/视频产物走 OSS + CDN

- OSS 建 bucket（私有读写）+ 绑定 `cdn.你的域名.com`（CNAME 已在 §8 配）
- 后端生成签名 URL 下发前端（对齐技术方案 §8 存储设计），主机磁盘零占用
- 月成本：¥10–50 量级（按量）

### 9.8 备案等待期怎么联调（不用等 2–4 周）

| 需求 | 备案期方案 |
|---|---|

## 12. 常见问题

**Q：个体工商户和企业备案有区别吗？**
流程一致。个体户执照也能备案、开微信支付、办 AIGC 登记；但部分支付/AIGC 材料审核对企业更顺。单人团队起步用个体户完全可行（R16 两者皆可）。

**Q：能不能不备案，用境外服务器？**
技术上能跑，但**微信内打开未备案域名会触发拦截/风险提示**——本产品主入口在微信生态（服务号菜单/模板消息/对话框），等于自断主通道。备案是必经之路，且免费，只是花 2–4 周等待。

**Q：备案期间能开发吗？**
能，且应该——见 §9.8，IP 直连联调 + mock 微信授权，等备案号的 2–4 周正好完成开发与内测。

**Q：先上线后补备案行不行？**
不行。管局以「域名可访问时间」倒查，未备案先开站会被接入商（云厂商）直接封 80/443，且留下不良记录影响后续审核。
