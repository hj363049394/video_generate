# 小红书内容生产标准提示词 v1.0

> 来源：2026-09 POC 全链路验证（对标笔记 → 仿写 → 图文 → 视频）
> 用途：标准化"拆解仿写 → 图文 → 视频"三个环节中提供给模型的提示词，生产新笔记时按流程取用。
> 数据流总览：提示词①拆解 → 提示词②仿写（产出**内容单元**，即图文同源的数据基础）→ 提示词③按内容单元生图 → 提示词④按内容单元生成分镜口播。

---

## 使用流程

```
对标笔记数据(标准JSON) ──→ ①爆款拆解 ──→ 拆解报告
                                          │ + 账号人设配置
                                          ▼
                              ②仿写生成 ──→ 仿写稿 + 内容单元(JSON)
                                          │
                    ┌─────────────────────┴─────────────────────┐
                    ▼                                           ▼
          ③配图生图(文生图/图生图)                    ④视频分镜与口播
                    │                                           │
                    ▼                                           ▼
              图片组(封面+内页×3)                    分镜脚本 → TTS → 合成
```

## 提示词 ① · 爆款五层拆解

**使用时机**：拿到对标笔记结构化数据后。**输入变量**：`{对标笔记JSON}`、`{目标赛道}`。

```text
你是一位小红书爆款内容分析师。请对下面这篇对标笔记做五层拆解，输出结构化拆解报告。

## 对标笔记数据
{对标笔记JSON}

## 目标赛道
{目标赛道}

## 拆解要求（五层，逐层输出）

1. 选题层：赛道定位、击中的痛点/爽点、目标人群画像、提供的情绪价值（收藏欲/共鸣/实用/晒圈货币）
2. 标题层：钩子类型判定（数字型/悬念型/反差型/痛点型/时效型）、关键词选择、emoji 用法、标题公式抽象（如"时令+人群+目的地+承诺"）
3. 正文层：结构骨架还原（逐段标注功能：钩子开头→痛点共鸣→干货主体→互动引导）、段落节奏（信息密度、分行习惯）、口吻人设、话题标签策略（大流量词+精准词的搭配逻辑）
4. 视觉层：封面形态（大字报/照片+字/纯照片）、信息层级、色调风格、图组信息分工（每张图承担什么职责）
5. 数据层：赞藏评比例解读——收藏>赞=干货工具型（用户怕找不着，收藏价值高）；赞>藏=情绪共鸣型；评论高=争议/求助互动型；结合热门评论提炼真实共鸣点（用户到底在认同什么、问什么）

## 输出格式
- 每层一个小节，先给结论再给证据（引用原文片段）
- 最后输出「可复用要素清单」：明确哪些是本次仿写应保留的结构性要素（结构公式、钩子模式、标签策略、图组分工），哪些是必须替换的主题性要素（主题、案例、数据、点位）
```

## 提示词 ② · 同构异题仿写（含内容单元产出）

**使用时机**：拆解报告完成后。**输入变量**：`{拆解报告}`、`{账号人设}`、`{对标笔记JSON}`。

```text
你是一位小红书内容创作者。基于拆解报告，按"同构异题"策略仿写一篇笔记。

## 拆解报告
{拆解报告}

## 我的账号人设
{账号人设}
（示例：定位=提供行程规划的旅行家，提供行程定制服务；口吻=懂行的朋友，不端着；服务钩子=评论区帮粉丝按人数天数定制行程）

## 仿写规则（同构异题）

1. 保留：结构骨架、钩子模式、段落节奏、排版符号习惯、标签策略、图组信息分工
2. 替换：主题细节、案例、点位/产品、数据、人设口吻——替换幅度要大到"一眼是新内容"，但结构对齐要精确到段
3. 差异化：对标笔记讲"去哪"，我的版本按人设强化"怎么排/怎么做"的规划感（天数、节奏、决策依据表格化）
4. 软广处理：对标笔记中的商业植入（约40%篇幅的软广段）一律删除，替换为人设专业价值（如方法论、避坑原则），不得引入任何新商业植入
5. 结尾必须有服务钩子：与账号变现路径一致（如"评论区报人数/天数/需求，我帮你重排一版"）
6. 标签：保留对标标签的结构逻辑（大流量词+精准词），替换具体词条以匹配新内容
7. 原创红线：不得复用原文连续 8 字以上片段；结构同构但文字全新

## 输出格式（严格按此结构）

### 1. 标题候选 ×3
按对标标题公式生成，标注推荐项及理由

### 2. 正文全文
小红书发布格式，含 emoji 与分段

### 3. 内容单元（关键产物，供图文与视频同源使用）
输出 JSON 数组，每个元素对应一张图：
[
  {
    "slide": 1,
    "role": "cover | itinerary | highlight | spots | service",
    "on_image": "该图上呈现的全部信息点（标题字/卡片/标签等）",
    "voiceover_basis": "基于本图信息点的口播要点提示"
  }
]
图组标准结构：封面（钩子）→ 路线/总览（收藏价值）→ 重点展开（情绪点）→ 干货细节（时段/价格/避坑）→ 服务钩子（转化）

### 4. 话题标签列表
```

## 提示词 ③ · 配图生图（Seedream 文生图 / 图生图）

**使用时机**：内容单元确定后，为每张图生成底图。**给生图模型**（非 LLM）。

### 3a. 封面·图生图（对标封面要素替换，首选）

```text
参考这张图的构图、色调和画面氛围，将场景替换为{目标场景描述}：{场景要素1}，{场景要素2}，{场景要素3}，温暖午后光线，旅行摄影风格，竖版构图，画面干净，无人物，无文字，无水印
```

- `{目标场景描述}`：仿写内容的核心地标/主体（如"南京明孝陵石象路秋景"）
- `{场景要素}`：具体视觉锚点（如"古石像分列道路两侧、金色梧桐树成荫、地面铺满落叶"）
- 参考图：对标笔记封面原图 URL
- 尺寸：1728x2304（3:4）；模型名 `doubao-seedream-5.0-lite`（Agent Plan 专属命名，最小 3686400 像素）

### 3b. 文生图（内页横幅/插图）

```text
{场景主体描述}，{氛围与光线}，{风格锚点}，{构图方向}，无人物，无文字，无水印
```

风格锚点按赛道选用（保持全组图统一）：

| 赛道 | 风格锚点 |
|---|---|
| 旅行·秋色 | 金色梧桐/银杏，暖秋色调，温暖午后光线，旅行摄影风格 |
| 旅行·海岛 | 阳光沙滩，清澈海水，明亮通透色调，度假感旅拍风格 |
| 美食 | 食材质感特写，暖光，日系清新风格 |
| 城市探索 | 街景人文，生活气息，自然光纪实风格 |

### 3c. 生图铁律

1. **中文文字一律不让 AI 画**——AI 只出无字底图，所有标题/文案由排版层（PIL）渲染，规避错字变形
2. 全组图共用同一组风格锚点，色调统一
3. 信息密度高的内容（路线表/点位卡/原则清单）用排版卡片承载，AI 图只做横幅与情绪图

## 提示词 ④ · 视频分镜与口播文案（图文同源）

**使用时机**：图组生成后。**输入变量**：`{内容单元JSON}`。

```text
你是短视频编导。基于以下内容单元，生成视频分镜脚本。铁律：图文同源——每段旁白只讲对应图片上呈现的内容，图上没有的信息不进旁白（可微调衔接词）。

## 内容单元
{内容单元JSON}

## 口播文案改写规则
1. 去书面化：删 emoji、删标签符号，短句，口语连接词
2. 每镜头 1 个信息组，25~45 字（约 6~10 秒），超过 45 字拆镜头
3. 开头 3 秒必须有钩子（痛点/悬念/承诺）
4. 结尾固定服务钩子（对齐账号变现路径）
5. 时长估算：中文口播约 4.5 字/秒

## 输出格式（JSON 数组）
[
  {
    "shot": 1,
    "image": "对应图片文件",
    "voiceover": "口播文案（图上有什么讲什么）",
    "est_seconds": 8
  }
]

## 合成参数标准（非模型输入，供脚本执行）
- 音色：清新女声 zh_female_qingxinnvsheng_uranus_bigtts（旅行赛道验证款；备选清单见附B）
- Ken Burns：奇偶镜头交替缓推(1.0→1.18)/缓拉(1.18→1.0)
- 转场：crossfade 0.5s（音频同步 acrossfade）
- BGM：轻快尤克里里/原声吉他类，音量 16%，首尾 1.5s/2.2s 淡入淡出
- 每镜头时长 = 旁白时长 + 0.9s 呼吸感；整体首尾 0.5s 淡入淡出
```

## 附录 A · 变量与输入 Schema

**对标笔记 JSON（提示词①输入）**：note_id / url / title / content / cover_image / images[] / tags[] / likes / collects / comments / shares / published_at / author{name, followers} / top_comments[]（手动导出或红狐 `get_note_detail` 产出）。

**账号人设（提示词②输入）**：定位一句话 / 目标人群 / 口吻描述 / 服务与变现路径 / 禁忌（如"不接软广"）。
